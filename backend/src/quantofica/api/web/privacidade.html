Política de privacidade

Versão de {{DATA}}. Vale para o app SC Mercados (Android) e para as páginas deste endereço.

O SC Mercados é uma lista de compras da casa, compartilhada entre quem mora junto, que mostra quanto a lista fica em cada mercado de Blumenau. Para isso guardamos o mínimo: não pedimos e-mail, telefone, senha nem CPF.

Quem cuida dos seus dados

O controlador dos dados é {{RESPONSAVEL}}, responsável pelo SC Mercados. Para qualquer pedido sobre seus dados, inclusive falar com o encarregado (LGPD, art. 41), escreva para {{CONTATO}}.

O que nunca guardamos

  • CPF: ao ler um cupom, o app nunca lê o campo do CPF do consumidor.
  • Localização: o app não tem permissão de localização.
  • Contatos, fotos e áudio: a câmera só é usada na hora, para ler o código de barras ou o QR do cupom, e a imagem não sai do celular.

Não vendemos dados, não temos anúncios e não usamos ferramentas de rastreamento de terceiros.

Base legal

Usamos seus dados para prestar o serviço que você pediu (LGPD, art. 7º, V). Os registros técnicos de acesso têm como base o legítimo interesse em manter o serviço seguro (art. 7º, IX).

Onde os dados ficam

Em servidores nos Estados Unidos: o banco de dados na Supabase e a API no Render. É uma transferência internacional necessária para prestar o serviço (LGPD, art. 33, IX), com provedores que se comprometem contratualmente com a proteção dos dados. A lista também fica guardada no seu celular, para funcionar sem internet.

Quem vê o quê

Só quem está na sua casa (quem entrou pelo seu convite) vê a lista e os apelidos. O link de convite abre a lista na web para quem tem o código; não compartilhe o código com quem não mora com você. Os dados de uso podem ser usados de forma agregada e anônima (por exemplo, "quantas casas compararam preços nesta semana"), nunca ligados a uma pessoa.

Seus direitos

Você pode, a qualquer momento (LGPD, art. 18):

  • ver e corrigir seus dados no próprio app (apelido e bairro ficam no Perfil);
  • apagar seus dados: no app, em Perfil → Seus dados → Apagar meus dados, ou pela página Apagar meus dados;
  • pedir uma cópia, saber com quem compartilhamos ou tirar dúvidas pelo e-mail {{CONTATO}}. Respondemos em até 15 dias.

Por quanto tempo

Enquanto você usar o app. Ao apagar seus dados, saem na hora o apelido, o vínculo com a casa e os códigos de acesso. Se você era a última pessoa da casa, saem também a casa, as listas e o resumo dos cupons. Se outras pessoas continuam na casa, os itens que você pôs ficam na lista delas, sem o seu nome. Os registros técnicos somem sozinhos em poucos dias.

Crianças

O app é para maiores de 18 anos, que fazem as compras da casa.

Mudanças

Se esta política mudar, a data no topo muda e, quando a mudança for importante, avisamos no app.
